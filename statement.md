 Project Statement: Library Management System

## 1. Problem Statement

A library has to keep track of things such as which books are available, which books have been borrowed, and who has borrowed them. When this information is written down and managed manually, it can take extra time to find a record. It can also be easy to make a mistake or forget to update a book's status.

For this project, I want to make a small Library Management System using Python. It will bring a few common library tasks together in one menu-driven program and make them easier to manage.

## 2. Scope of the Project

I am keeping the project focused on basic library work so that it is suitable for a first-semester student. The user will be able to add, display, and search for books, enter student details, issue and return books, calculate a simple fine, and view a summary of the records.

The basic version will run in the terminal. It will not be an online library system, and it will not include advanced features such as multiple user accounts or a full database unless these are added later.

## 3. Who Can Use It?

The project is mainly intended for:

- A librarian who wants to manage simple book records.
- A student who wants to see how a basic library program works.
- A beginner learning how Python functions and modules can solve a practical problem.

## 4. Main Features

1. **Book management:** Add new books, display the book list, and search for a book.
2. **Student details:** Enter and view basic student information.
3. **Issue a book:** Check that a book is available before recording that it has been borrowed.
4. **Return a book:** Update the record when a borrowed book is returned.
5. **Fine calculation:** Calculate a simple fine using the number of late days entered by the user.
6. **Library summary:** Show useful counts, such as the total number of books and how many are available or issued.

These features will be included in the final version as they are implemented and tested.

## 5. Expected Outcome

By the end of the project, I expect to have a working Python program that lets a user choose library tasks from a menu. While building it, I will practise using functions, conditions, loops, lists, dictionaries, and separate Python files. I will also learn how to test a program and explain its design in a project report.

## 6. Tools and Concepts

- Python 3
- VS Code or another Python editor
- Git and GitHub
- Basic input and output
- Conditions and loops
- Functions and modules
- Lists and dictionaries

## 7. Possible Future Improvements

At the moment, the project is designed as a simple learning exercise. In the future, I could add permanent data storage, due dates, more detailed fine calculation, and a graphical user interface.
